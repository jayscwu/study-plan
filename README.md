# 學習計畫進度追蹤

一個讀寫 Google Sheet 學習計畫的網頁，讓學生與家長掌握學習進度。支援登入、學生每日登錄上課進度、家長從儀表板查看進度，以及家長交代任務與「學生回報完成 → 家長審核」的流程。電腦與手機瀏覽器皆可使用。

## 功能

- PIN 碼登入（4 位使用者：2 位家長＋2 位學生）
- 上課進度：依課程分頁、單元卡片列出每個學習項目，學生按一下就能切換「待學習／學習中／上完課」，日期預設今天、可以補登過去的日期（不能填未來）。退回「學習中」會清掉上完課日期，退回「待學習」會清掉兩個日期。家長也可以幫學生修改
- 上課進度可以切換「手風琴／看板」：看板每個科目一欄（欄頂有進度條，欄內可上下捲動），單元可收合且一次只展開一個，進入時自動展開第一個還沒上完的單元；卡片用顏色區分狀態，點狀態標籤選新狀態、點日期旁的 ✏️ 改日期。可依科目、狀態複選篩選，選用的檢視和篩選會記在這台裝置的瀏覽器裡
- 儀表板：整體上課進度、各科進度（點開可看各單元並直接修改）、最近 7 天動態、學習中清單，以及逾期／今日／明日任務；家長另外會看到待審核回報的提醒
- 任務管理（家長專用頁籤）：依「課程 → 單元」新增／編輯／刪除任務，並審核學生送出的完成回報
- 任務回報：任務顯示在「上課進度」對應的單元卡片裡，學生按「回報完成」，家長核准後任務才會變成已完成；家長拒絕的話學生可以重新回報
- 響應式版面，手機也能操作

## 架構

```
瀏覽器 (GitHub Pages 靜態頁: index.html / style.css / app.js / api.js)
   │  fetch (JSON)
   ▼
Google Apps Script Web App（獨立專案，不綁定任何一份試算表）
   │  openById 分別讀寫
   ▼
四份各自獨立的 Google Sheet：登入帳號 / 課程單元 / 學習任務 / 上課進度
```

前端本身不儲存任何資料，所有讀寫都透過 Apps Script 這層 API。這是**一次性設定**，設定完成後平常只要維護 Google Sheet 內容即可（「課程單元」由你自己維護；「學習任務」「上課進度」平常由前端寫入，不需要手動編輯）。

## 一次性設定步驟

### 1. 建立四份 Google Sheet

**「登入帳號」**（手動填入 4 位使用者）

| 姓名 | 角色 | PIN |
|---|---|---|
| mason | 學生 | 自訂 4 位數字 |
| (學生2姓名) | 學生 | ... |
| (家長1姓名) | 家長 | ... |
| (家長2姓名) | 家長 | ... |

⚠️ 「學生」角色的姓名必須與「學習任務」分頁裡「學生」欄位的值**完全一致**，否則篩選不到資料。

**「課程單元」**（手動維護，三個階層依序往下排）

| 項次 | 階層 | 課程單元 |
|---|---|---|
| 1 | 1 | 七上國文 |
| 2 | 2 | 國文第1課 |
| 3 | 3 | 第1課-夏夜(上)-作者與背景簡介 |
| 4 | 3 | 第1課-夏夜(下)-課文內容說明 |
| 5 | 2 | 國文第2課 |

- 階層 1 = 課程、2 = 單元、3 = 學習項目。每一列屬於往上最近一個階層比較小的列
- 學生登錄上課進度的對象是階層 3；階層 1、2 的進度由下層自動算出
- ⚠️ **項次是固定編號**，上課進度用它對應學習項目。已經有人登錄進度後，不要重新編號；新增項目時給一個沒用過的新號碼即可，畫面上的順序是照列的位置排，不是照項次
- 課程、單元的名稱也被「學習任務」引用，改名後舊任務會對不到單元（畫面上會列在該課程的「其他任務」）

**「學習任務」**（留空表頭即可，平常由前端「任務管理」頁籤寫入，不需要手動編輯。「課程名稱」填階層 1 的名稱，「單元名稱」填階層 2 的名稱）

| 學生 | 課程名稱 | 單元名稱 | 任務名稱 | 狀態 | 預計學習日期 | 時段 | 回報狀態 | 回報時間 | 審核人 | 審核時間 | 建立人 |
|---|---|---|---|---|---|---|---|---|---|---|---|

**「上課進度」**（留空表頭即可，由前端「上課進度」頁籤寫入。一位學生的一個學習項目一列，沒有資料的項目視為「待學習」）

| 學生 | 項次 | 課程單元 | 狀態 | 開始學習日期 | 上完課日期 | 更新人 | 更新時間 |
|---|---|---|---|---|---|---|---|

四份檔案各自獨立（不同的 Google Sheet 檔案），把網址列裡 `/d/` 和 `/edit` 中間那一段（檔案 ID）記下來，設定 Apps Script 時會用到。

### 2. 部署 Apps Script 後端

1. 前往 [script.google.com](https://script.google.com) → 新增專案（**不用**從 Google Sheet 的「擴充功能」進入，這次是獨立專案）
2. 刪除編輯器裡預設的程式碼，貼上 [apps-script/Code.gs](apps-script/Code.gs) 的完整內容
3. 把檔案開頭這四行的 ID 換成你自己剛剛建立的四份 Sheet 的檔案 ID：
   ```js
   const ACCOUNTS_FILE_ID = "換成你的登入帳號檔案 ID";
   const COURSE_UNITS_FILE_ID = "換成你的課程單元檔案 ID";
   const TASKS_FILE_ID = "換成你的學習任務檔案 ID";
   const PROGRESS_FILE_ID = "換成你的上課進度檔案 ID";
   ```
4. 右上角「部署」(Deploy) → 「新增部署作業」(New deployment) → 類型選「網頁應用程式」(Web app)
   - 執行身分 (Execute as)：**我**（你自己的帳號）
   - 存取權 (Who has access)：**所有人** (Anyone)
5. 點「部署」，第一次執行會跳出 Google 授權畫面，請同意存取這四份 Sheet
6. 複製產生的網址（格式類似 `https://script.google.com/macros/s/xxxxx/exec`）

**之後更新 `Code.gs` 時**：貼上新程式碼、存檔後，到「部署」→「管理部署作業」→ 點鉛筆圖示編輯 → 版本選「新版本」→「部署」。這樣網址不會變，前端不用改。如果新程式碼用到新的 Sheet，Google 會再要求一次授權。

### 3. 設定前端

打開 [api.js](api.js)，把第一行的網址換成剛剛複製的那個：

```js
const APPS_SCRIPT_URL = "貼上你的 Apps Script 網址";
```

存檔後，若已發佈到 GitHub Pages，把改動 push 上去即可生效。

### 4.（建議）收回 Google Sheet 的公開共用權限

設定完成、確認登入、上課進度、新增任務與回報審核都正常運作後，可以把四份 Sheet 的共用權限改回「限制」（只有你自己或指定帳號能開啟），因為之後前端都是透過 Apps Script（用你的帳號執行）讀寫，不再需要 Sheet 本身公開。

## 安全性說明

PIN 碼是給家庭成員快速辨識用的**輕量機制**，不是正式的帳號密碼安全機制（沒有錯誤鎖定、沒有額外加密）。適合家庭內部使用，請不要用來保護重要或敏感資料。

## 本機預覽

**不能直接雙擊開啟 `index.html`**（網址會變成 `file://...`），瀏覽器會擋掉跨網域請求。請透過本機網頁伺服器開啟：

```powershell
# 在專案資料夾（StudyPlan）底下執行
powershell -NoProfile -Command "Get-Content -Raw '.claude/server.ps1' | Invoke-Expression"
```

啟動後用瀏覽器開啟 `http://localhost:5173`。若電腦有裝 Node.js 或 Python，也可以用 `npx serve .` 或 `python -m http.server 8000`。

## 部署到 GitHub Pages

1. 將此資料夾推送到 GitHub repository
2. Repository 設定 → Pages → Source 選擇分支的根目錄
3. 儲存後幾分鐘內即可透過 GitHub 提供的網址存取
